# 跨端故事化新手引导、首次播放提示与自绘示例素材大纲（`onboarding-spec.md`）

> **适用里程碑**：M0 架构大纲定义；由 Wave 3 · M5（S51 完整剧本与素材生成器、S52 Flutter 引导实现、S53 Android 电视与手机引导实现）补全细化文案与代码落地。  
> **红线声明**：严格遵守仓库「不内置、不提供、不托管影视资源」边界（`MainActivity.java` 首次地址保持 `""` 空串）；示例卡片严禁出现任何真实影片名、真实剧照、公共影视资料库数据或第三方商标图形。

## 1. 五幕式故事化引导结构（S51 剧本大纲）

引导流程采用 `AuroraBackground` / `AuroraView`（电视端为静态暗色渐变）衬底，共 **5 幕**，任意一幕均可一键「跳过」直达应用主界面，并在「设置 -> 关于与帮助 -> 重新查看新手引导」提供常驻重看入口：

| 幕次 | 核心主题 | 展示组件与合规要点 | 三端差异化交互重点 |
| :---: | :--- | :--- | :--- |
| **第 1 幕** | **自有配置与工具边界** | 显著展示「仅作播放与内容管理工具，不内置、不提供任何影视资源」声明；预览空地址导入框（默认 `""`） | **电视**：局域网扫码推送示意 + 遥控输入；**手机/平板**：剪贴板一键粘贴 + 本地 JSON 选择；**桌面**：地址粘贴 + 备份还原 |
| **第 2 幕** | **海报墙、规格徽章与续播** | 使用 `12–16` 张程序生成的抽象几何示例海报（右上角强制带 **「示例」** 角标）展示海报网格、文字规格徽章（`4K`、`DV · ATMOS`、`HDR10+`、`REMUX`）与继续观看进度条 | **电视**：方向键焦点弹簧缩放体验；**手机/平板**：横竖屏自适应列数；**桌面**：悬停规格提示与宽屏多列排版 |
| **第 3 幕** | **多端同步（WebDAV / 局域网）** | 图示 `marco-movie-sync` v2 协议同步观看历史、收藏与公开订阅，明确说明隐私空间与网盘/Emby 登录凭据本机隔离 | 三端统一展示「自配 WebDAV 云盘」与「同一局域网点对点免云盘直连同步」双路径 |
| **第 4 幕** | **进阶播放操控与 HUD** | 动态演示新播放页 HUD（起播规格提示、细进度条、跳过片头倒计时、分片弹幕）与核心操控手势 | **触控**：长按 `2.0x` -> 横滑 `0.5x..3.0x` -> 上滑锁定、三区双击、左右半屏亮/音；**电视**：长按右键逐级加速 + 上键锁定、确认键暂停；**桌面**：短按/长按 `→`、`Space`、`[`/`]`、`D` 键开关弹幕、滚轮音量 |
| **第 5 幕** | **个性化外观与立即开始** | 预览减少动态效果、减少透明效果、界面缩放（Android `100% / 110% / 120%`、Flutter 动态字号），底部提供「立即导入配置」与「先进入首页」双主按钮 | **电视**：首屏默认聚焦「立即导入配置」，返回键可退回上一幕或跳过；**iPad / 桌面横屏**：采用左右分栏宽屏卡片排版 |

## 2. 首次播放手势提示（`FirstPlayGestureHint`）

1. **触发条件**：
   - 用户首次进入点播视频播放且画面成功起播后（避开 `StartSpecOverlay` 左上角区域，在底部主控栏上方居中弹出轻量半透明引导条）。
   - 桌面端展示键鼠快捷提示条（`长按 → 倍速 · 滚轮音量 · D 弹幕`）；触控端展示手势微提示（`长按倍速 · 左右滑调速 · 上滑锁定`）；电视端展示遥控提示（`长按右键加速 · 上键锁定 · 返回恢复`）。
2. **频控与永久关闭默认值**：
   - 最多自动展示 **`3` 次**（每次进入新播放会话且停留满 `2s` 计 1 次，展示 `4500ms` 后自动淡出）。
   - 气泡内附带可点击/可聚焦的 `「知道了 / 不再提示」` 按钮，点击后立即置 `dismissed = true`，后续永不自动弹出（除非用户在设置中手动重置/重看引导）。
3. **跨端持久化键名约定**：
   - **Android（`Prefs.java`，置于 `Prefs.KEYS` 备份数组之外以保持 `ReviewFixChecks.java:191` 长度 `46` 不变）**：
     - `ONBOARDING_DONE_VERSION = "onboarding_done_version"`（`int`，默认 `0`，当前引导版本为 `1`）
     - `PLAY_HINT_SHOWN_COUNT = "play_hint_shown_count"`（`int`，默认 `0`，上限 `3`）
     - `PLAY_HINT_DISMISSED = "play_hint_dismissed"`（`boolean`，默认 `false`）
   - **Flutter（`StorageService` / `SharedPreferences`）**：
     - `onboarding_done_version`（`int`，默认 `0`，目标 `1`）
     - `play_hint_shown_count`（`int`，默认 `0`，上限 `3`）
     - `play_hint_dismissed`（`bool`，默认 `false`）

## 3. 自绘示例素材生成器（`scripts/generate_demo_art.py`）与合规校验规范

1. **零版权争议程序化生成（S51 实现）**：
   - 使用固定随机种子（`seed = 20261120`）纯代码绘制 **`12` 至 `16` 张** `2:3` 竖版抽象艺术海报（几何光影折线 + `motion-tokens.json` 品牌渐变色板 + 胶片颗粒噪点），每张海报画面右上角直接绘制清晰可读的 **`「示例 / DEMO」`** 角标。
   - 配套生成 `demo-manifest.json`（中英双语占位元数据），标题严格限定在虚构占位名集合内，例如：
     - `示例 · 远航` / `Sample · Horizon`
     - `示例 · 城市微光` / `Sample · City Glow`
     - `示例 · 深空信标` / `Sample · Deep Beacon`
     - `示例 · 海岸季风` / `Sample · Coastal Wind`
   - 所有生成脚本、图像与 JSON 清单均采用与主仓库一致的 **`GPL-3.0-only`** 许可，并在脚本头部注明版权与 SPDX 标识。
2. **与 `scripts/check_public_content.py` 二进制守卫的兼容方案（关键技术约束）**：
   - **已核实仓库现状**：`scripts/check_public_content.py:160-163` 对入库文件逐一做 UTF-8 文本解码检查，当前**仅对 `.png` 后缀豁免跳过**（`if p.suffix == '.png': continue`），而未登记的 `.webp` 二进制文件会直接触发 `unexpected binary` 报错导致门禁失败！
   - **M0 默认规范（决策点 #6）**：
     - **默认方案（零守卫脚本改动）**：`scripts/generate_demo_art.py` 输出量化压缩后的 **`.png` 格式**（`360x540`，8-bit 索引调色板 + 抖动，单张 `<= 35 KB`，14 张合计 `< 480 KB`）及 UTF-8 `demo-manifest.json`，无需改动 `check_public_content.py` 即可原生通过公开内容合规扫描；或进一步辅以运行时 `Canvas` / `CustomPainter` 矢量直绘。
     - **备选方案（若用户拍板优先使用 `.webp`）**：不得对任意 `.webp` 开通全局免检口子，必须像 `CONFORMANCE_INPUT_SHA256` 一样在 `check_public_content.py` 中逐文件固定 `SHA-256` 白名单。

## 4. 平台边界与不在范围内（Out of Scope）

1. **HarmonyOS NEXT 隔离**：`OhosRuntime.isOhos` 为真时默认跳过首开引导与首次手势提示，保持现有鸿蒙启动流不变；`flutter/ohos/` 与 `flutter/lib/ui/tv/**` 严禁修改。
2. **Android Lite（API 14）与 Apple TV（`tvos/`）**：本轮不引入新手引导。
3. **离线可播放视频样片打包与独立「演示播放器」模式**：不在仓库或安装包内新增任何 `.mp4` / `.mkv` 视频流或演示字幕文件（避免增大包体及触发 `check_public_content.py` 视频拦截）；第 4 幕统一使用轻量矢量/组件级交互动效示意。
4. **首页常驻伪造排行榜、电影票根待看架、拟物书架或虚构评分装饰**（遵守 `docs/COMPATIBILITY.md:36`「删除无真实数据依据的评分装饰」原则）。
