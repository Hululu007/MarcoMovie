# Marco Movie macOS 0.6.0

发布日期：2026-11-25。应用版本 `0.6.0`（构建号 `72`），架构支持 Apple Silicon（`arm64`）与 Intel（`x86_64`）通用桌面应用。本次更新全面打磨 macOS 桌面浏览、播放字幕避让、剧集识别与弹幕同步、离线双轨 HLS 下载校验、直播首帧稳定性及应用内更新体验，完整保留 `0.5.20` 本地订阅、收藏、观看进度与设置数据无损覆盖升级。

## 更新内容

- **底栏弹出字幕自动上移避让与平滑复位**：播放器底部进度条和工具栏唤出或拖动进度时，独立字幕层与 `libmpv` 内嵌字幕（含双行 ASS/SRT 文字字幕及 PGS 图像字幕，内嵌 `libmpv` 升级至 `v0.7.3` 以完整支持 `pgssub` 解码）自动上移高于控制栏上沿；保留 ASS 顶部标识原位，并覆盖窄窗、普通全屏及超宽裁切（`BoxFit.cover`）几何计算；手动或自动收起底栏均等待淡出完毕后再平滑复位，仅剩细进度线时恢复原位，视频画幅、弹幕位置与拖动区保持稳定。
- **播放器内直接识别 / 校准本集与弹幕精准绑定**：在播放器选集面板新增「识别／校准本集」，直接复用 `SeriesScrapeSheet` 并定位当前播放文件，展示原文件名、识别作品与季集及判断依据，修正后即时从当前播放时间点重新加载对应弹幕并保持原有播放/暂停状态；按「用户已确认 > Emby/片源结构化季集与容器 MKV 层次标签 > 原文件名/目录季集」优先级判定（无可靠证据显示「待确认」），防止正作误播或误绑外传/预告，同时按作品+季+集精准换线。
- **弹幕源 WebDAV 独立同步与多端无损合并**：新增独立「同步弹幕源」开关与旁路文件同步，完整支持多设备新增、置顶首选、删除与重排的三向合并（保留远端新增与重排、传播主动删除、保持首行插入优先级），按端点隔离认证凭据与「无需认证」忽略状态，并修复设置面板调透明度覆盖云端新源及关闭同步后仍在途写入的问题。
- **宽/窄窗桌面浏览体验与窗口记忆**：优化 macOS 首页与详情页宽/窄窗自适应布局、交通灯顶部避让与 `PosterExpandRoute` 展开动效；统一宽窗与窄窗「继续观看」及观看历史真实进度展示（已知时长 0% 渲染真实 0%，未知时长隐藏进度条，不再虚构 15%）；原生记忆并校验正常窗口位置与尺寸（最小 `720×520`，多屏拔出自动夹回主屏并保留红绿灯可见，兼容全屏/最小化切换）。
- **离线双轨 HLS 下载完整性加固**：完整支持主清单独立音频组（`#EXT-X-MEDIA:TYPE=AUDIO`）双轨下载与本地代理离线播放；严格校验 `BYTERANGE` `HTTP 206` 的 `Content-Range` 与实收字节数，拒绝错区间、短 `206` 及普通无 `Range` 请求返回的残缺 `206` 响应，杜绝残缺分片写入可续传缓存，源站恢复后重试同一任务即可完整恢复音画并保留合法 `HTTP 200` 切片回退。
- **直播首帧四态状态机与防黑屏/防误换源**：将直播起播显式划分为 `tracksUnknown`、`confirmedAudioOnly`、`awaitingVideoFrame`、`videoFrameRendered` 四态；未确认轨道前或先报音轨后晚发现视频轨时持续保护加载提示并重新武装首帧超时恢复，无时钟推进但持续渲染帧的直播流不再误换源，同时保留纯音频广播、主动暂停挂起超时、旧台信号隔离与同分辨率切台稳定表现。
- **macOS 应用内检查更新与校验**：接入镜像站（`updates/macos.json`）与 GitHub Release 双源检查，区分远端新版、同版与本地新版，下载时隔离暂存并校验文件大小与 SHA-256，校验通过后支持在 Finder 中显示安装包。
