# Marco Movie Android 电视 / 盒子 0.6.3

发布日期：2026-11-27。应用版本 `0.6.3`（版本代码 `100`）；最低 Android 6 / API 23（32 位 `armeabi-v7a`）。本次为 Android 电视 / 盒子端深度稳定性、搜索体验与遥控流畅度专项升级：重构 Apple TV 风格全局搜索与分页保焦预算引擎，优化历史页与 200 源切换弹窗帧率，修复受保护音轨解码回退、网盘过期链接续播与长压线程稳定性，并新增首次启动官方渠道提示与联系/反馈二维码入口。

## 本次更新

- **电视端 Apple TV 风格全局搜索升级、分页保焦与多源预算治理**：
  - 全新发现/空态页展示「近期热搜剧目」与最近搜索记录；过滤纯空白、全角空格与不间断空格输入（零无效网络请求）；
  - 精确/模糊分层匹配与无歧义「来源 + 影片」二元身份去重，修复含冒号源键（如 `film` 与 `film:hk`）跨源合并漏片与误回收；
  - 区分首批展示上限与搜索总量上限，首页全无关时跨页取全不丢后续命中；在 24→36+ 分页展开、慢源结果迟到及 900 条满额预算回收时保持当前卡片焦点与滚动偏移稳定，详情页返回原卡片；
  - 规范 1080p、720p 与 1.3× 字体缩放下的卡片元数据排版与单 View 海报渲染，搜索连续移焦帧耗显著收敛。
- **遥控器历史页、200 源切换弹窗与海报墙流畅度优化**：
  - 优化历史页冷/热打开与返回帧耗、预热网格渲染与多源海报加载调度；
  - 优化 200 源切换弹窗列表快速定位、翻页及移焦响应，多源切换后稳定恢复首页焦点锚点与多源本地存储隔离。
- **音频解码回退、网盘续播重解与长压稳定性修复**：
  - 受保护/加密音轨按实际加密状态与渲染器能力保留可用平台解码器（避免 FFmpeg 软解拒收 DRM 导致无声），同时完整保留小米电视等设备明文 AC-3 / E-AC-3 软解与 AAC 原选路；
  - 修复网盘代理播放链接过期（`HTTP 410`）后的自动重解续播，强化同线分季改名与季别移除守卫（不误跳扫码备用线路）；
  - 治理高频切源/换集长压下的线程泄漏与慢请求堆积，消除 `pthread_create` OOM 风险。
- **首次启动官方防伪声明与「联系与反馈作者 / 赞助支持」二维码入口**：
  - 首次启动温和展示永久免费防伪声明与唯一官方地址（`marcotv.wlj9919.top`），设置页与更新页提供离线二维码直达官网交流群（`https://marcotv.wlj9919.top/movie/#group`）与自愿赞助页（`https://marcotv.wlj9919.top/movie/#donate`）。
