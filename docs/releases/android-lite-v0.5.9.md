# Marco Movie Android Lite 0.5.9

发布日期：2026-11-24。应用版本 `0.5.9`（versionCode `59`）。专为 Android 4.0+（API 14+）老旧电视、机顶盒与老手机打造的超轻量单 DEX 独立版本（包名 `com.pilipala.marcomovie.lite`，可与标准版共存）。本次更新聚焦观影稳定性、遥控器容错、标准片源与解析适配，以及跨版本升级后的观看历史与收藏归属保护。

## 更新内容

- **播放会话隔离与遥控器容错**：观看历史与续播严格绑定实际播放会话，直播切换、自然结束、退出或重建播放器不再覆盖点播历史或误触发下一集；坏线路、无响应或解析失败状态下仍可用遥控器打开工具栏切换备用线路或返回，迟到的旧线路错误与准备超时不会打断新线路或抢回焦点；投屏控制桥严格绑定当前投屏会话，退出投屏后不会干扰本地播放。
- **结构化选集、同集换线保进度与跨季隔离**：同时兼容传统 `vod_play_from / vod_play_url` 与结构化 `vod_play_list`（含裸 URL 数组自动顺序编号），保留同名不同编码线路并合并重叠选集；历史持久化线路编码实现精准续播；同集换线（如 `EP2 → 第02集`）保留当前播放进度，中文/英文季号冲突及跨线路共享短标识冲突时保持当前播放并弹出选集，手动选择不同季未看剧集时从头起播且不串用旧进度。
- **片源解析、严格 MacCMS XML、直播与连续编辑**：支持 HTTP(S) JSON 解析接口传参、按线路路由与全局解析头合并（保留跨域请求头保护）及相对路径补全；严格 `type=0` XML 源在分类、翻页、搜索与详情页正确区分 `ac=list / ac=videolist` 并保留自定义参数；支持仅含直播的配置独立导入、`proxy://` 外部节目单 Referer 传递及 M3U 百分号编码请求头解码；连续编辑片源保留既有手动覆盖（区分继承、手动指定与主动清空），显式 XML 源改名保类型、切换至明确 JSON 接口自动改用 `ac=detail`。
- **订阅切换、搜索反馈与历史/收藏归属保护**：手输导入、扫码替换与切子仓统一当前源选择并重置旧分类与请求，首次扫码导入后“当前源”立即可用，跨源导航与历史重排按影片身份恢复焦点；单源与全站聚合搜索准确区分 HTTP 200 HTML/XML 错误页、JSON 错误码与带标准 `<!DOCTYPE rss>` 的有效零命中；兼容 `0.5.8` 旧删除墓碑防止同步复活已删记录，在仅加载单一来源但本地存在多来源证据时保护未归属旧历史与收藏，打开旧记录前弹出确认或恢复原源入口。
