# Marco Movie Android 电视 / 盒子 0.5.26

版本代码：90；最低 Android 6 / API23。

## 本次更新

- V17 原生电视界面、密集海报墙、搜索标题右侧横向来源选择。左导航使用贴边渐变轨道和轻玻璃焦点；Logo固定在导航顶部，展开显示品牌文字且不挤压正文。
- “我的”按钮等宽单行，大字号可随焦点横向滚动；设置中的可聚焦项直接随上下键移动并滚入视野。取消连按三次上键回顶部。
- 电视搜索支持用拼音首字母联想已索引的影视片名（相关：[#40](https://github.com/Pilipala9919/MarcoMovie/issues/40)），不代表实时热门词或全站片库联想。保留双击系统输入法、组合态和候选页；修复多源分页与异步失效。私密匹配不再隐式学习到普通索引，旧派生缓存保留但不自动导入新索引。
- 详情保留加载/失败信息及收藏，历史显示集名、进度、总时长和已看完状态。点播上键进入暂停标记，下键访问进度，退出恢复原暂停状态；直播上下仍换台。
- V2绝对标记节点与旧片尾剩余秒数分开保存，不重解释旧数据；URL型集身份仍仅会话有效。修复短片尾循环触发闩及续播字幕时长处理。
- 媒体识别结合有界内容探测、MIME和播放器行为处理伪装后缀，保留鉴权、Range及错误回退。实际ISO光盘不等同于MP4伪装ISO后缀。

## 验证边界

标准Android TV/手机共用的搜索、播放基础代码受到影响；不重新设计手机界面。Lite使用独立源码，本次补丁未覆盖。其他平台现有更新保持不变。

API28 ARMv7隔离测试覆盖了指定的片库、搜索、详情、设置导航、短循环、升级/前向回退、HTTP/HTTPS和字幕场景。最新ISO/MP3伪装MP4案例均取得150条真实播放器进度及视频尺寸样本；大字号末端按钮滚入已观察。用户另对现场隔离素材确认了画面、声音及遥控正常，这不是所有设备或全部格式通过。

隐私原反例和两项缓存/长标题回归已独立复验。API28小米电视上的独立测试包还实际验证了合成私密数据的匹配/学习隔离、退出后普通索引保持干净、页面重建与冷进程恢复，公开与合成私密数据摘要保持；本轮隔离升级保留了20项偏好和测试配置。这些结果不代表正式应用全部用户数据迁移、PIN交互或真实账号测试。

Android6未取得可用原生环境。ADB黑色视频Surface截图不代表面板黑屏或画面正常；用户现场音画/遥控确认限定于当时的隔离素材。真实网盘改名MP3的取流及画面输出（相关：[#31](https://github.com/Pilipala9919/MarcoMovie/issues/31)）未在真实账户路径验证，不据受控素材测试认定已解决。真实子路径重定向攻击与全部设备/格式也不在本轮原生验证范围。合成数据前向回退结果不保证任意用户数据无损迁移。
