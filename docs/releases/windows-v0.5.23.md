# Marco Movie Windows 0.5.23

应用版本：`0.5.23`（构建号 `73`）。本次只更新 Windows，继续使用已确认的柔光背景设计与原有用户数据。

## 更新内容

- 首页缩短焦点横幅，增加完整推荐海报网格；继续观看与推荐同时展示，宽窗下继续观看放在横幅右侧。保留密度、卡片信息及首页模块开关。
- 详情页独立展示海报、标题与评分。宽窗采用影片信息和片源选集双栏，小窗自动改为上下布局；剧集改为紧凑按钮，保留换源、线路、选季、正倒序、全部剧集、收藏、下载和续播。
- 统一设置中的播放、首页排版、高级选项，以及网盘账号和同步子页的面板与文字样式。支持当前浅色、深色和自选背景，保留原有设置与账号流程。
- 修复升级后的桌面图标刷新：安装包为桌面和开始菜单快捷方式显式指定当前版本图标；沿用原安装位置和安装范围，并刷新已有桌面快捷方式。保留既定品牌标识。

## 功能与数据

沿用 0.5.22 的片源解析、播放器、下载、同步和隐私隔离逻辑。未更改订阅、账号、收藏、观看记录及下载任务的存储格式；其他平台保持原版本。

## 验证说明

发布记录另附本次自动化检查、Windows 实际操作与播放验收结果。第三方个人账号和外部服务的可用性不作为本次受控测试的通过项。
