# Marco Movie iOS / iPadOS 0.5.31

发布日期：2026-11-15。应用版本：`0.5.31`（构建号 `81`），最低系统要求：iOS / iPadOS 14.0。本次更新围绕 4K 网盘原画播放、玩偶系 / 四盘聚合源检索与前后台挂起恢复进行深度架构升级，带来 6 路并发分片回环代理、同站死链自动回捞与 CatPaw / DRPY 本机引擎自愈能力。

## 4K 网盘播放与片源解析升级

- **6 路并发分片回环代理与首尾秒拖（`NetdiskRangeProxy`）**：为夸克、UC、百度、阿里云盘高码率 4K / 杜比视界原画直链新增本机 `6 路 × 1 MB` 滑动窗口并发分片代理（内存上限 `24 MB`），完整支持 `HEAD` 与 `HTTP 206` 字节区间请求；播放 MKV / MP4 大体积原盘执行尾部索引探测或大幅拖动进度条时自动取消旧偏移预取，消除单连接限速卡顿，并在上游 `401` / `403` 签名过期时无感刷新直链续传。
- **玩偶系 4K 全站兼容与同站同名死链自动回捞（`WoggNetdiskAdapter`）**：全面覆盖玩偶哥哥、木偶、蜡笔、剧透、快影、虎斑、蜗牛、多多、闪电、至臻、米粒、星剧社等 20+ 套 MacCMS 4K 网盘站点与易搜 / 米搜 / 盘搜 / 聚剧四盘轮询配额聚合；精准锁定详情页下载链接容器（杜绝误抓侧栏推荐片源），并在主条目网盘分享全部失效或目录为空时自动并发检索同站同名其他条目补齐可用剧集。
- **夸克 / UC / 百度网盘分享解析加固**：修复夸克与 UC 分享桌面/移动 UA 兼容及临时转存根目录空间回收，保持百度网盘分享子目录原始 `sekey` 透传契约与直链解码兼容，针对取消分享、空文件夹及 RAR/7z/分卷压缩包资源给出明确诊断说明。
- **本机 CatPaw / DRPY 回环服务自愈与并发 DoH 防污染**：修复 iOS 切后台挂起唤醒后回环端口失活导致的 `Connection refused` 连锁失败，新增套接字健康探活、自动重启与 6 Worker 并发搜索超时隔离，并内置并发 RFC 8484 DoH（阿里 / 腾讯 DNSPod）清洁 IP 解析与 HTTPS SNI 重连。
