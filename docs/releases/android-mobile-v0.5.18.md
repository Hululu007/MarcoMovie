# Marco Movie Android 手机 / 平板 0.5.18

发布日期：2026-11-11。版本代码：75。

## 续作罗马数字检索与选集封面防串图

- 扩展搜索变体引擎（`SearchVariants`），为带序号的续作标题自动双向补齐阿拉伯数字、罗马数字（`II`–`IX` / `Ⅱ`–`Ⅸ`）、`第X季` 与中文数字写法；在未主动检索“漫剧 / 动态漫 / 短剧”时，合并多写法召回结果并将正片剧集/动漫排在衍生漫剧之前。
- 手机端聚合搜索优先调度顶栏当前选中的片源，将当前源过滤胶囊置顶在“全部”之后，并在结果列表中直观展示分类标签（正片与漫剧分色标识）。
- 修复详情页竖版封面升级与分季识别逻辑（`ImmersivePoster` / `MobileDetailScreen`）：保留续作裸数字与“动态漫 / 漫剧”载体修饰词，当片源已提供有效 HTTP 海报时仅执行同源 CDN 无损升级，不再以模糊片名抓取第三方封面覆盖原海报，避免正片与漫剧封面或分季互相串联。

## 设置页对齐 iOS 液态玻璃胶囊与底部抽屉布局

- 重构手机与平板端“设置”页（`MobileIosSettings`），采用与 iOS 端一致的 `32sp` 大标题、自适应单列/双列 `36dp` 圆角液态玻璃胶囊网格（外观、浏览、播放、订阅与账号、数据、关于与更新）及 `74%` 屏高液态玻璃底部抽屉。
- 抽屉内支持流式面包屑胶囊导航、系统返回键逐级回退、苹果蓝 `✓` 流式选项丸与实时生效的“玻璃磨砂强度”调节，同时完整保留自定义壁纸、解码与隧道播放、片头片尾跳过、字幕样式、手机网页快传、Emby 直连、CatPaw 配置、跨平台备份恢复与在线更新检查。

## 网盘账号中心与插件原生弹窗液态玻璃重设计

- 重设计手机端顶栏“网盘”入口面板（`AccountPanel`）为液态玻璃底部抽屉与彩色矢量图标胶囊卡（云盘账号授权与开关、局域网推送凭据、网盘线路优先顺序、网盘搜索结果排序、CatPaw 本机配置），保留电视端遥控器锚定菜单。
- 新增运行时宿主窗口玻璃美化层（`PluginDialogStyler`）：在不修改或解包任何第三方扩展二进制的前提下，自动剥离扩展配置弹窗的灰白割裂底色，将网盘“已登录 / 未登录”“启用中 / 停用中”按钮重塑为深色液态玻璃双胶囊行并实时跟随状态刷新，同时收敛超宽扫码布局、补齐二维码白色圆角静区衬底。

## 手机端全局交互与细节打磨

- 移除详情页无真实评分时的哈希估算分数，仅在取得真实评分时展示评分徽章。
- 将全集网格、分季切换、分类筛选、Emby 登录、隐私空间 PIN 输入与局域网配置弹窗统一为深色液态玻璃抽屉或圆角玻璃卡片，消除浅色原生弹窗割裂感，修复手机端弹窗强制沉浸式状态栏闪烁与软键盘遮挡问题。
- 为所有底部抽屉补齐手势导航条安全边距；修复直播页切换分组残留搜索词与上千频道一次性渲染卡顿（改为每批 120 频道分页加载）；为片库收藏增加单项移除与缺源聚合搜索回退，为清空历史增加二次确认；恢复手机横屏播放器顶栏当前集数副标题。

## 验证范围与限制

- 通过公共内容守卫检查、Java 代码格式检查、全部离线纯 JVM 单元回归（含续作罗马数字检索与漫剧降权新增断言），以及 Android 双端正式签名构建与包体校验。
- 本版本仅发布 Android 手机 / 平板安装包（`MarcoMovie-0.5.18-android-mobile.apk` 及兼容别名 `MarcoMovie-0.5.18-mobile.apk`），使用官方正式签名，支持应用内直接覆盖安装升级；不变更电视端、Lite、Windows、macOS 或 iOS 已发布版本。
- 自动化构建与离线/模拟器回归不代表特定实体手机型号或真实第三方网盘账号播放已完成实机验收。
