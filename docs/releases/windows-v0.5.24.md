# Marco Movie Windows 0.5.24

发布日期：2026-11-17。应用版本：`0.5.24`（构建号 `74`）。本次更新延续柔光背景桌面界面与完整本地用户数据兼容，集中修复中文输入法搜索回车误触、播放器鼠标微小抖动频繁唤醒控制栏及网盘伪装 `.mp3` 视频黑屏问题，并新增 WebDAV 仅同步订阅源模式与 JSON 备份文件直接读写能力。

## 更新内容

- **中文输入法拼写组合态保护（`#27`）**：搜索框与直播频道筛选识别 Windows 中文输入法 `composing` 选词状态，拼音未上屏前按回车不再提前触发残缺英文搜索，并补齐柔光面板透明交互层兼容。
- **播放器鼠标唤醒防抖与快速收起（`#50`）**：去重桌面指针悬停/移动事件，控制栏隐藏后需 `350ms` 内累计位移达到 `12px` 以上才重新唤醒，桌面端空闲自动隐藏时间缩短至 `2.2s`，消除桌面轻微震动导致的控制栏反复弹出。
- **网盘伪装 `.mp3` 视频原画播放（`#31`）**：夸克、UC、百度、阿里云盘分享自动将 `>= 15 MiB` 的伪装 `.mp3` 文件纳入可播视频列表，并在 `mpv` 强制开启 `vid=auto` 与禁用纯音频封面模式，正常输出视频画面。
- **WebDAV 仅同步订阅源模式与 JSON 备份文件读写（`#44` / `#47`）**：云端同步新增「同时同步观看历史与收藏」开关（关闭后仅同步订阅源并保留云端已有观影记录）；备份恢复弹窗支持直接导出 `.json` 备份文件与从本地选择 `.json` 文件恢复。
