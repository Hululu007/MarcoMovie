# Marco Movie Android 电视 / 盒子 0.5.29

版本代码：93；最低 Android 6 / API23。

## 本次更新

- **电视直播高清化升级**：新增多源直播频道智能聚合与画质优选策略，支持按实测分辨率与码率优先匹配 4K / 1080P、IPv6 及内网组播转单播（udpxy）线路，自动缓存实测画质；补齐 XMLTV 电子节目单（EPG）与 IPTV 时移回看能力，并接入 Emby Live TV 直播频道与直链播放。
- **首页与片库合一浏览**：取消左侧导航独立的「片库」入口，精简为首页、搜索、直播、我的、网盘、投屏、设置 7 项；首页去掉与继续观看重复的顶部大卡片，向下滚动直接进入片库，同步展示片源切换、「推荐 / 电影 / 电视剧 / 综艺 / 动漫」等分类与筛选、以及无限滚动海报墙。
- **动态封面自适应柔光与壁纸工坊**：重构背景柔光引擎为 3 组动态漂移呼吸光团，提升封面取色饱和度与明度并放宽柔光遮罩，随遥控器焦点切换平滑溶变全屏色彩；同时支持预设渐变主题、自定义双色调节及手机扫码上传自定义背景壁纸。
- **Apple TV 风格分栏设置页**：电视端设置页重构为全屏固定分栏架构，顶部标题/时钟与左侧一级分类固定不动，右侧设置项独立平滑滚动，整体增大边距与留白呼吸感。
- **沉浸式影视详情页重构**：优化海报与剧名视觉重心至屏幕左侧中部偏下，剧名旁配精致小巧的空心/红心收藏按钮；依次呈现真实年代/地区/总集数、豆瓣与烂番茄评分徽章、独立的「开始/继续播放 + 选集与线路」弹窗操作行（防止超长集名挤出选集按钮）、下方展示线路对应单集文件名与精简观看进度、完整剧情简介以及纯展示不可选中的圆形头像演职员表。播放中按返回转背景播放逻辑保持不变。
- **电视搜索升级**：扩充近期热门中文影视词库并异步拉取公开热门片单（隐私空间严格隔离），输入拼音首字母即可联想可选中文片名；搜索框右侧扫码入口替换为纯矢量二维码图标。

## 验证边界

- **自动化主机回归**：发布前已运行 Java 格式检查（234 文件）、公开仓库合规与隐私模式扫描（1348 文件）及 10 套 Android/TV 主机回归测试（覆盖直播画质优选/udpxy/Emby/EPG、投屏与扫码上传、详情评分与文件名去重、搜索热门联想与隐私隔离、V17 标记与输入法安全边界、首页刷新等），全部通过。
