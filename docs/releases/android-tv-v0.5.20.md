# Marco Movie Android 电视 / 盒子 0.5.20

发布日期：2026-11-11。版本代码：77。

## 新版悬浮卡片播放器与比例自适应

- 电视端新增现代悬浮卡片播放界面（默认启用，可在“设置 → 播放与解码 → 播放页样式”中随时切换“新版悬浮卡片 / 经典工具栏”）：采用底部紧凑磨砂悬浮控制卡片，整合当前片名与分集、圆形矢量操作按钮（播放/暂停、下一集、选集、字幕、音轨、换源、倍速、更多）、纤细胶囊进度条、实时流媒体技术参数徽章（如 `4K` / `1080P`、`DOLBY VISION` / `HDR10` / 视频编码、杜比全景声 / 声道格式、解码方式）与等宽数字时间码；点击字幕、音轨、换源、倍速或更多时在对应按钮上方平滑弹出带矢量图标与胶囊选中态的悬浮菜单。
- 引入基于视口物理分辨率比例的自适应单位换算，卡片宽度、高度、圆角按钮、弹窗菜单与多级字号均随屏幕比例自适应缩放，避免界面缩放档位（`110%` / `120%`）或系统字体放大导致控制卡片过大；重做右上角实时时钟为细体等宽数字与自绘居中双圆点冒号，并修复 Android 9（API 28）设备进入新版播放页时 `SeekBar.setMinHeight` 的方法兼容问题。

## Dock 栏焦点框收敛与海报墙观看历史

- 保持电视端 Dock 导航栏原版胶囊毛玻璃外框与胶囊提示气泡样式，将内部滑动选中焦点框收敛为低调克制的方形圆角微光样式，不再喧宾夺主。
- 电视端“观看历史”页面由纯文字列表重构为 4–6 列竖版海报墙，右上角展示当前观看剧集/资源标签，海报底部叠加渐变遮罩、观看百分比（如 `已看 87%` / `已看完`）与白色进度条，下方显示片名与观看时间码；按确认键继续观看，长按确认键或按菜单键可单独移除记录，右上角支持一键清空历史。

## 滚动、动画与毛玻璃掉帧优化

- 优化 `FocusMotion` 遥控器焦点缩放与描边复用（缓存 `GradientDrawable` 与缩放动画参数，消除每次移焦重复创建背景对象）、`GlassSelection` 预分配单位渐变着色器矩阵、`TvScrollView` 物理帧驱动平滑滚动、`HomeAmbient` 离屏低分辨率缓存预模糊氛围背景，以及 `GlassworkSurface` 取消逐帧 `Canvas.clipPath` 改用 `BitmapShader` 圆角直绘并对背景变化做合并节流，显著降低分类切换、海报墙翻页与遥控器连续移焦时的主线程绘制开销。

## 验证范围与限制

- 通过全部离线 Java / Python / Node 回归检查、公共内容守卫检查、GitHub Actions Android 双架构编译与 API 23 电视模拟器回归，并在小米电视（`MiTV-ASTP0`，Android 9，`1920×1080`）完成覆盖安装、首页 Dock、海报墙观看历史及新版播放页悬浮卡片与上拉菜单实机验证。
- 本版本仅发布 Android TV / 盒子安装包（`MarcoMovie-0.5.20-android-tv.apk` 及兼容别名 `MarcoMovie-0.5.20-preview.apk`），使用官方正式签名，支持应用内直接覆盖升级；不变更手机、Lite、Windows、macOS 或 iOS 已发布版本。
- 单一型号电视实机验证不代表所有第三方电视/机顶盒固件或外部片源网络延迟均已完成穷举验收。
