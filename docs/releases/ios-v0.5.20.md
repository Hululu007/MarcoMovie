# Marco Movie iOS / iPadOS 0.5.20

发布日期：2026-11-11。应用版本：`0.5.20`（构建号 `70`），最低系统要求：iOS / iPadOS 14.0。本次更新集中修复 iOS 实机反馈的五大问题：四大网盘（夸克、UC、百度网盘、阿里云盘）本机直接跳转 App 授权与扫码登录、百度带提取码分享播放失败、选集详情页失效备用分享提示刷屏与夸克目录误报、全站并发搜索多线路读取失败，以及设置页底部 Dock 上层高遮罩遮挡问题。

## 核心修复与优化

1. **四大网盘本机直接跳转 App 授权与扫码登录全链路修复**
- **阿里云盘（我的阿狸）**：修复扫码确认登录后因官方 `bizExt` 内置中文昵称采用 GBK 编码（含 `0x5C` 尾字节边界）导致 UTF-8 解码抛出异常、误报“网盘账号验证未完成”的问题；为 iOS / iPadOS 新增原生 `WKWebView` 移动授权页（`marco_movie/netdisk_auth`），点击「本机跳转授权」可直接完成本机号码一键免密、唤起淘宝 App（`tbopen://`）一键授权或验证码登录并自动提取 `refresh_token`，同时支持一键保存二维码并拉起阿里云盘 App（`smartdrive://`）相册扫码。
- **百度网盘（我的嘟嘟）**：移除 iOS 端无效的安卓专用 `bdnetdisk://n/action.EXTERNAL_LINK` 链接；接入百度 Passport 官方移动端原生授权通道（`wappass.baidu.com` + `bdnetdisk://com.baidu.passport/grantweb` / `baiduyunipad://` / `baiduboxapp://`），点击「本机跳转授权」可直接唤起本机百度网盘 App 原生「授权登录」确认页，授权返回后自动交换并校验 `pan.baidu.com` 域 `BDUSS` 与 `STOKEN`。
- **夸克网盘（我的夸父）与 UC 网盘（我的优汐）**：补齐 iPhone 与 iPad 独立官方 `appkey` 协议（`qklink://`、`qkcloudlink://`、`uclink://`、`ucliteioslink://`），按设备形态优先唤起对应客户端确认页，并在未安装客户端时自动回退应用内网页登录；同时修复点击跳转后二维码轮询定时器未续期的问题。

2. **百度网盘带提取码分享播放与区域 CDN 重定向修复**
- 修复带提取码百度分享在请求 DLNA 原画直链时 `sekey`（`randsk`）发生二次 URL 编码及账号标识回退错误导致的签名失败，并支持 `d.pcs.baidu.com` 多级区域 P2SP CDN HTTPS 跳转与跨域 `Cookie` 隔离。
- 同步包含本地 `CloudMediaProxy` 探测流断连回收与高码率起播缓冲超时自动清晰度降档机制。

3. **详情选集页提示折叠与夸克目录误报修复**
- 修复夸克公开分享目录因历史删减文件导致原站 `_total` 偏大时误报“目录返回不完整”的问题；已有可用播放线路时自动将失效的备用网盘分享折叠为单行摘要（可点击展开查看明细）。

4. **全站搜索多线路并发读取稳定性提升**
- 为内置本地脚本宿主新增启动串行队列与无 JIT 解包超时余量，并对共用同一插件包的多个站点实施单次并发下载去重，消除并发争抢导致的批量“暂时无法读取”。

5. **设置页底部 Dock 透明穿透对齐主页**
- 移除设置页外层重复叠加的底部裁剪高度与安全区硬截断，列表内容可直接滚动穿过半透明液态玻璃 Dock，不再遮挡“关于与更新”与“数据”区域。

## 验证范围与已知限制

- 通过公共内容守卫检查、Python / JS / CatPaw 运行时检查、iOS 原生壳层注入幂等测试及全部 `658` 项 Flutter 自动化测试（覆盖阿里 GBK `bizExt` 解码、百度与阿里本机跳转会话交换、夸克/UC 手机与平板协议路由及设置页视口布局）。
- 未签名 IPA（`MarcoMovie-0.5.20-ios-unsigned.ipa` 及兼容别名 `MarcoMovie-0.5.20-ios-iphone-ipad-unsigned.ipa`）支持巨魔（TrollStore）覆盖安装或自签工具签名安装；自动化测试不代表已使用用户私人真实账号对全部第三方网盘客户端完成实机验收。
