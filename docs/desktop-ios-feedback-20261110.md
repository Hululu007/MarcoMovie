# Windows / macOS 对照 iOS 用户反馈复核

2026-11-10，基于已发布 Windows 0.5.9 / macOS 0.5.8 的桌面主线 `0ff394a3108b4814bcefb3c2f478f58374bd4f46` 逐项核对原始反馈。两端使用同一套 Flutter 源码和网盘适配层，以下遗漏均影响两个桌面版本。

| 原始反馈 | 桌面核对与修复 |
| --- | --- |
| 玩偶哥哥出现无关采集线路 | 上一版已移除内置采集池与跨来源补线。本次继续保留这一约束，并修复单个分享面板含多个标签时的网盘名称错配。 |
| 百度扫码后仍显示未扫码、会话不完整 | 复现字符串状态被忽略、响应 Cookie 未保存的问题。保留每个二维码独立会话和长轮询进度；完成网盘页面登录并验证真实账号后才保存。STOKEN 按服务实际返回处理；一次性扫码票据不能充当账号，也不会在补全登录重试时重复兑换。 |
| 选择夸克资源却提示百度登录问题 | 复现线路标签错配；发现播放失败后的自动线路切换仍可跨网盘。本次以文件稳定引用识别网盘，并阻止自动跨网盘、跨分享恢复；手动选线保留。 |
| 玩偶 4K 详情从旧观看记录／收藏读取失败 | 旧串源版本的编号不一定属于原站。本次只在同一导入源内检索唯一片名匹配，校对详情标题，恢复原站目录并提示重新选择文件；无匹配或多匹配明确报错。不会拿同名外站影片替代，也不把旧进度套到其他文件。 |
| 连续点击快进／后退 15 秒触发背景手势 | 桌面背景双击用于切换全屏，因此表现为误切全屏。按钮与视频手势改为兄弟层；鼠标和触控的连续点击测试验证两次跳转均生效，背景双击仍可用。 |
| 选集页中间重复显示播放线路、扫码入口 | 桌面现有布局没有 iOS 的重复中间栏。保留顶部入口和选线弹窗中的扫码功能。 |

另外同步原目录子文件夹路径、百度提取码、分享并发与取消、夸克部分目录警告和 UC 播放代理暂停生命周期修复，避免实际文件因接口字段、单路超时或暂停而被丢弃。

原审阅的下载文件隔离、夸克临时文件清理范围、二维码后台轮询、短视频时长判断、播放策略名称和桌面安装包校验已在桌面主线处理；本次全量回归覆盖这些既有行为。iOS 专属编译、签名及手机界面不替换桌面实现。

## 验证方法与边界

在旧桌面基线运行新增复现用例，响应 Cookie、字符串扫码状态、原分享标签归属三项均失败；修复后通过。本地完整 Flutter 回归 568 项通过，平台生成检查 7 项通过。新测试覆盖百度真实账号验证成功／失败、补全登录重试、Cookie 作用域、旧编号零／唯一／多个匹配、原文件恢复策略及鼠标／触控按钮。

网盘接口测试使用合成响应，没有使用用户账号或修改云盘。实际本机 HTTP、Node、QuickJS 回归与原生构建不能代替 Windows / Mac 用户账号、会员文件或 HEVC/HDR 影片的实机播放验收。正式发布记录另列两端原生 CI、版本、构建提交及安装包校验结果。
