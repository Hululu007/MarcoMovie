# Windows 0.5.10 / macOS 0.5.9 录屏反馈复核

用户确认上述版本仍存在片源读取和播放停在 00:00 的问题。三段录屏显示 Windows 窗口；macOS 同类表现由用户确认。

## 已定位并修复

- 录屏对应订阅的插件摘要为 `88e67402129e7db92669fb351397ecd4d09709e6c70b577f22a19cfb0ad5f204`，与上一轮 iOS 使用的 `da3f3a7afcfcded4d58d9c3a574dfb5cb2ddcc3db4290b7d8b3a7346f9ee8096` 不同。原适配检查拒绝前者。增加了经静态核对的 WoGG、T4、FY、DM84、Auete 和 Bttwoo 配置；保留旧版本。插件作为数据读取，不执行导入的 DEX、Python 或原生库。
- 夸克目录接口携带账号会话，但原画媒体请求遗漏会话。原插件还会接收接口轮换的 Cookie。现在同一播放操作接收有效轮换，并通过限定夸克 HTTPS 域名的临时本地传输读取原画与转码。播放器不持有账号 Cookie；跨提供方跳转、账号切换及取消均受检查。
- 原画保持 Range 读取；HLS 中的子列表、分段和密钥按提供方范围转发。同一文件的画质选项共享生命周期，外部签名 CDN 不携带账号 Cookie。
- 为片源解析和媒体起播增加等待上限。只有实际进度前进才结束起播计时；失败可以重试或选择其他画质。
- 不同订阅中的同名插件不再仅按插件 key 去重；搜索侧栏和错误信息显示订阅区分，同源成功结果清除过期提示。

## 证据与范围

私有实际订阅在线检查返回首页 120 条、“疯狂动物城”7 条、“精武英雄”1 条；新旧插件数据提取及当前插件完整 Guard 引导通过。原始订阅、站点地址、插件及录屏不纳入公开源码。

新增合成鉴权测试覆盖下载接口到媒体请求的会话轮换、超过 8 GiB 的 Range 偏移、HLS 分段、账号切换、重定向边界、起播超时和跨订阅搜索。桌面构建增加打包解码库的 HEVC/AAC MKV 进度、暂停与定位检查。

合成媒体测试验证传输和原生解码链路，不等同于用户账号下 72.8 GB 原片实播。未使用用户账号进行网盘转存或播放；物理 Mac 和该片完整 4K/HDR 播放尚未验收。第三方源本身的验证码、失效分享和服务不可用仍按实际结果报告。
