## 3. 已通过的 Android 16 真机验收记录

- **最终签名 APK 离线双 MAP HLS 跨段播放（通过）**：
  - 测试设备：Android 16 / API 36（Xiaomi 14 Ultra，`arm64-v8a`），实机安装 `base.apk` SHA-256 与最终签名包 `fb816102d5a15a1ea8d000827a0ddd1efc4b7212565c5413ccec3302e366a2db` 逐字节一致。
  - 入口与配置：从「我的片库 → 离线下载 → 播放」打开离线双 MAP 音画分离 fMP4 HLS 样本（第 12 秒更换音视频初始化片段并时间戳归零，画面从 `640×360` 切至 `960×540`，音频从 `44.1 kHz` 切至 `48 kHz`）。**全局内核选择 `MPV` 时，本次播放自动单次回退到 `Media3`（界面 HUD 显式标注 `Media3（单次回退）`），全局偏好仍保留为 `MPV` 未被改写。**
  - 自然播放跨过 12 秒：Period 0 实帧由 `00:00:01.583`（帧 `38`）推进至 `00:00:07.792`（帧 `187`），`AudioFlinger` 活跃音轨 `44100 Hz` 持续推进（`+102,312` 帧）；跨过 12 秒后无缝切换为 `960×540` 画面与 `48000 Hz` 活跃音轨（`+120,960` 帧）；离线期间新增媒体 HTTP 请求为 `0`。
  - 重开后依次拖动 `16s → 3s → 18s`：`16s` 输出 `960×540` 画面与 `48000 Hz` 音轨（`+101,760` 帧）；`3s` 切回 `640×360` 实帧推进（帧 `95` → `151`）与 `44100 Hz` 音轨（`+102,312` 帧）；`18s` 切回 `960×540` 画面与 `48000 Hz` 音轨（`+103,680` 帧）；离线期间新增媒体 HTTP 请求为 `0`，`ApplicationExitInfo` 零崩溃。
  - 沿用同机已通过的六组对照矩阵结果：全局 `Media3` 下双 MAP 自然跨段与 `16s → 3s → 18s` 拖动通过；全局 `MPV` 下单 MAP 离线 HLS（零网络）与普通 MP4 均由实际 `MPV` 播放通过。
- **沿用已通过的同机实测记录**：
