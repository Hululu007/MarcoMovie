# 隐私与数据处理

Marco Movie 不要求注册项目账号，不配置项目运营的用户数据服务器。应用自身没有接入广告或统计 SDK；用户主动导入的扩展行为不在这一陈述的保证范围内。

## 设备上保存什么

应用可在自身存储空间中保存用户导入的配置、配置地址、界面与播放偏好、搜索记录、收藏（来源标识、内容标识、标题和海报地址，最多 300 部）、观看历史（内容标识、标题、海报地址、线路、集数与进度）、壁纸，以及用户启用扩展后由扩展产生的文件。搜索匹配还会在内存中学习标题。观看历史最多保留 60 部，不单独保存临时播放地址；内容标识或海报地址本身仍可能包含来源提供的信息。系统自动应用备份在清单中关闭。

详情响应仅在内存中短期缓存（最多 24 条、5 分钟），其中可能包含来源提供的剧集标识或地址；不另外缓存播放解析接口返回的临时直链。详情耗时诊断仅记录阶段耗时和缓存命中状态，不写入片名、来源地址、内容标识或账号凭据。

配置备份由用户主动导出，包含原始配置和部分偏好。原始配置里如有凭据，也会被导出；扩展单独保存的登录状态不包含在这份备份里。请自行保管备份文件。

## 网络访问

导入配置、加载海报、搜索、播放、导入图片地址、账号登录等操作会与用户配置或扩展指定的服务器通信。这些服务器可能接收 IP、请求头、搜索词以及用户配置提供的凭据。第三方服务的数据处理由对应提供方决定。

扩展能够在应用进程内执行，**不提供安全沙箱保证**。默认关闭扩展并不等于导入的其他远程内容完全无风险。只启用自己信任且有权使用的配置，切勿把私有凭据发到公开讨论区。

磁力功能被主动使用时涉及网络对等连接；对等节点可能看到网络地址。工具不替用户获得任何内容授权。

## 权限

- 网络权限：访问用户配置的服务和媒体。
- 音频设置权限：在设备支持时应用音效设置。
- 文件选择器：由用户主动选择配置、字幕、图片或备份文件；不申请全盘文件读取权限。

应用允许部分 HTTP 配置和媒体请求以兼容用户服务；HTTP 不提供传输加密。不要在不可信网络或地址中提交敏感凭据。

## 删除与报告

观看历史页面可删除单条记录或清空记录。设置中可清除搜索记录、重新加载首页内容和恢复部分默认偏好。卸载会移除应用自身数据，但不会自动删除用户导出的备份，也不代表撤销第三方服务授权；如需撤销授权，请到对应服务的账号管理中操作。

报告安全问题请阅读 [SECURITY.md](../SECURITY.md)，不要公开任何有效令牌或二维码。


## 局域网手机配置与多端网络同步

打开手机扫码配置或局域网接收同步时，设备临时启动局域网接收入口，二维码与配对地址包含一次性随机会话令牌，有效五分钟。关闭页面入口、切到后台或超时后立即停止接收，且仅响应局域网私有网段请求。二维码由本机离线生成，不发送到外部二维码服务。

应用提供可选的多端网络同步功能（`marco-movie-sync` v2），支持两种完全由用户自主控制的方式：

- **WebDAV 云同步**：仅与用户自行填写的第三方或自建 WebDAV 服务器（如坚果云、NAS、Alist、Nextcloud 等）通信，使用 HTTP Basic 认证读写同步 JSON 文件（上限 8 MB）。本项目不提供、不中转、不托管任何云同步服务器。WebDAV 密码保存在本机应用私有配置中，不会随配置备份或多端同步载荷导出。
- **局域网点对点同步**：在同一局域网的两台设备之间直接双向合并同步载荷，不经过任何外部服务器。

多端同步默认合并公开片源的观看历史进度、收藏列表、删除墓碑记录，以及可选开启的「同时同步我的订阅源配置」（仅限公开 HTTP(S) / 内联订阅源；若订阅文本中混有隐私条目，同步前会自动剔除隐私站点与隐私直播源）。**隐私空间（私密订阅、私密站点及其观看历史与收藏）、本机 `file://` 文件路径配置、各网盘账号 Cookie / Token 以及 Emby 服务器凭据均严格保留在本机，绝不写入 WebDAV 或局域网同步载荷，也不会被远端同步覆盖。**


## 软件更新请求

默认在应用首页前台每隔至少六小时检查一次公开版本信息，可在软件更新中关闭自动检查。请求发送至项目镜像站（marcotv.wlj9919.top）或 GitHub 官方基础设施，网络服务会接收连接所需的 IP 地址和应用更新器标识；不附带用户配置、观看历史、搜索词、网盘凭据或账号。

下载包暂存在应用私有缓存中，校验文件摘要、包名、版本和签名后才可交给系统安装器。安装需要用户确认；应用不会静默安装。镜像同步仅抓取公开发布文件，不收集电视数据。
